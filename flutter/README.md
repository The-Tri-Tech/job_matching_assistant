# Flutter Sample App

A simple Flutter application.

## Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) installed

### Platform Setup (if needed)
To generate or re-generate platform runner files (Android, iOS, Web, etc.):
```bash
flutter create .
```

### Running Locally
To run the sample app on your connected device or simulator:
```bash
flutter run
```

To run on Chrome (web):
```bash
flutter run -d chrome
```

### Running Tests
```bash
flutter test
```
